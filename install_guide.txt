일본어 도우미 앱 파일 (v3, 26-11-18 17시40분)

포함 파일:
- index.html: 앱 화면과 기능 (번역, 단어장, 복습, 사진 번역)
- sw.js: 화면 파일 저장 설정 (새 화면이 바로 반영되도록 네트워크 우선)
- manifest.webmanifest: 휴대폰 설치 정보
- icons 폴더: 앱 아이콘

설치 순서:
1. 이 파일들을 HTTPS 주소(예: GitHub Pages)에 올립니다. 파일 구조는 그대로 둡니다.
2. 갤럭시 크롬에서 그 HTTPS 주소를 엽니다.
3. 크롬 메뉴에서 '앱 설치' 또는 '홈 화면에 추가'를 선택합니다.

주의:
1. ZIP 파일을 풀지 않고는 설치할 수 없습니다. 압축을 먼저 풀어 올리세요.
2. 말하기, 듣기, 사진 글자 읽기는 인터넷과 크롬의 기능 지원, 마이크·카메라 권한이 필요합니다.
3. 번역은 공식 번역 서비스가 아닌 방식을 쓰므로 언제든 멈출 수 있습니다.
4. 기존 저장 데이터(jphelper_items)는 그대로 유지됩니다.
5. 단어 10,000개와 문장 10,000개 자료는 아직 포함되지 않았습니다.
6. 실제 휴대폰 설치와 기기별 동작은 HTTPS 배포 후 직접 확인해야 합니다.
